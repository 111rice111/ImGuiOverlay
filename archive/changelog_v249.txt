====== v2.49 更新日志 (2026-07-06) ======

【关键修复】持续锁敌不中断 + 走路同时自瞄 + 移除抖动机制

◆ 用户反馈
1. 自瞄效果不好, 稍微离开一点距离就不瞄准了
2. 希望持续瞄准, 走路时也要一直瞄
3. 不要加抖动机制

◆ 根因分析 (3 处停止追踪的代码路径)
1. 真实手指让权 → 走路时停止
   - 旧逻辑: Touch::GetFingerCount() > 0 → aim_slide_up 抬起让权 → 自瞄停
   - 用户走路时摇杆 finger=1, 触发让权, 自瞄完全不工作
   - 这正是"走路时不瞄"的根因

2. 死区内直接 return → 稍偏就停
   - 旧逻辑: dist < 15px 直接 return, 不再修正
   - 目标在屏幕中心 15px 内完全不追踪 → "稍微离开就不瞄"
   - 用户感知为"自瞄距离稍远就失效"

3. 漂移>80px 抬起重按 → 持续追踪间隙不修正
   - 旧逻辑: 漂移超 80px → aim_slide_up 抬起 → 下一帧重按
   - 持续追踪几秒后频繁抬起, 期间不修正 → 追踪不连续

◆ 修复方案
1. 移除"真实手指让权"机制 (核心)
   - slot 2 已与真实摇杆 slot 0 物理隔离(TypeA 用 slot 值作 Finger[] 索引,
     Upload 把 Finger[0]+Finger[2] 通过 SYN_MT_REPORT 分隔同时提交给游戏)
   - 自瞄与摇杆可在不同 slot 并行工作, 无需让权
   - 真实手指仅用于诊断显示, 不再干预自瞄
   - 效果: 走路按摇杆时自瞄持续锁敌

2. 死区改为衰减系数 (不再停止)
   - 旧: dist < deadzone 直接 return
   - 新: dist < deadzone 时 step 乘 (dist/deadzone) 衰减系数
     越接近中心修正越弱, 但不停止
   - 既持续追踪目标, 又避免中心 1-2px 抖动
   - 死区默认 15→5px (仅防 1-2px 抖动)

3. 漂移改为软回中 (不再抬起)
   - 旧: 漂移>80px → aim_slide_up 抬起 → 重按间隙不修正
   - 新: 偏离起手点>30px 时, 本帧 step 叠加 15% 回中分量
     既持续追踪目标, 又缓慢回中防漂移, 无抬起间隙

4. W2S 失败改为保持等待 (不再抬起)
   - 旧: W2S 失败 → aim_slide_up → 重按间隙不修正
   - 新: W2S 失败 → 手指保持当前位置不 move, 等待目标回屏
   - 连续失败 30 帧(~0.5秒)才彻底结束(防永久占 slot)

5. 默认参数优化
   - 平滑度 0.85→0.7 (系数 0.15→0.3, 更激进追踪, 减少延迟)
   - 死区 15→5px (仅防 1-2px 抖动, 不再"稍偏就停")
   - 最大追踪距离 30→50 米 (扩大追踪范围)
